# flutter_test_app

Aplikasi praktikum dasar Flutter. Layar utama menampilkan app bar `TI-RPL`
dan teks `Competence for competition!`.

## Menjalankan aplikasi

```shell
flutter pub get
flutter run
```

## Package

- `provider`
- `table_calendar`
- `fluttertoast`

Versi `provider` menggunakan rilis null-safe agar kompatibel dengan Dart 3.
